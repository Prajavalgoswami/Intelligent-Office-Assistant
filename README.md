# Intelligent Office Assistant

<img width="1792" height="592" alt="Gemini_Generated_Image_jv4256jv4256jv42" src="https://github.com/user-attachments/assets/3ada5ebf-c44b-4635-b115-efa6971997a3" />



An AI-powered office management platform that streamlines organizational communication, employee collaboration, document management, and administrative workflows. The system provides secure authentication, real-time messaging, document analysis using AI, notifications, and centralized employee management through a modern web interface.

---

> **Repository Scope**
>
> This README highlights the **Employee Module** of the Intelligent Office Assistant, showcasing its core functionalities such as authentication, communication, AI-powered document processing, notifications, and profile management. The complete project includes Company Admin and Super Admin modules and features that are not covered in this repository overview.

---

## 🚀 Features

- 🔐 Secure User Authentication & Authorization
- 👥 Employee & Profile Management
- 💬 Real-time Group Chat
- 📢 Organization-wide Broadcast Messaging
- 🤖 AI-powered Document Summarization & Question Answering
- 📄 PDF & DOCX Document Upload and Processing
- 🔔 Notification System
- 📁 Secure File & Image Sharing
- 📊 Responsive Dashboard

# ⚙️ Installation

## Clone Repository

```bash
git clone <repository-url>
```

## Backend

```bash
cd backend
npm install
npm start
```

## Frontend

```bash
cd frontend
npm install
npm run dev
```
